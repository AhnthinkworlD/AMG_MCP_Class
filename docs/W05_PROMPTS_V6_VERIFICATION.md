# 5주차 복사 프롬프트 v6 실제 실행 검증

2026-10-12 Windows의 TD 2025.33230, 기존 MCP 1.0.0/protocol2, 포트9987에서 새 요청문 01~05를 실행했습니다. AI가 목표와 조건을 해석하고 현재 상태·파라미터·지원 도구를 읽어 네이티브 MCP 호출로 제작·검사했습니다. 프롬프트를 자연어 해석 기능이 없는 서버에 직접 보낸 검사가 아닙니다.

세 예제의 TOX 재로드 픽셀 차이 0, 최종 오류 0·경고 0입니다. 기본 예제는 값0에서 크기0으로 사라지고 값.5의 지름은 값1의 약0.504배입니다. 기본 예제 검사 중앙 RGB는 값.5에서126/126/253, 값1에서253/253/253이었습니다. 이는 입력RGB와 렌더PNG의 차이를 포함한 관측값입니다.

기준 예제의 구조는 그대로 유지했습니다. 기본 구현은 새 기본 노드8개와 Geometry SOP 입력 구조·Noise 시간식 재사용이며 임의 코드로 도구 제한을 우회하지 않았습니다. 시험용 복제와 좌표 검사용 보조 노드는 제거했습니다. 좌표 읽기는 PNG8비트 정밀도의 보조 검사입니다.

검증 범위는 기준 예제가 들어 있는 수업 TOE와 현재 AI 환경입니다. 다른 AI 프로그램의 실기, 임의 빈 프로젝트의 무참조 생성, Mac TD 제작·렌더·Finder 실기는 검증하지 않았습니다. Mac 설치·stdio는 이전 원격 검사 결과를 유지하며 이번 프롬프트 검사와 구분합니다.

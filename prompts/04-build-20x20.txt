AMG_MCP로 검증한 10×10 원 예제를 20×20으로 확장해줘.
td_begin_session으로 프로젝트·Root·지원 기능을 확인하고 W05_PROMPT_PRACTICE를 찾아줘. 없으면 먼저 10×10 제작·검증 프롬프트를 실행해야 한다고 알려줘.
기존 10×10은 보존하고 새 Container W05_EXAMPLE_20X20으로 복사해줘. 이름이 겹치면 새 이름을 보고해줘.

1. 화면 조건
XY 평면에 위치가 고정된 20행×20열, 총 400개의 원이야.
Grid 크기 1×1과 정면 카메라 Width 1.1은 유지해줘.
간격이 줄어드니 Circle 반지름 X/Y는 0.025로 바꿔줘.
Noise TOP의 해상도도 20×20으로 맞춰 원 400개에 값이 하나씩 대응하게 해줘.
색 RGB=(v,v,1), Scale X=Y=v, Amp 0.5, Offset 0.5와 원래 시간식은 유지해줘.
복제한 네트워크의 참조가 새 Container 내부를 가리키는지 확인해줘.

2. 실제 검증
tx/ty/tz 각각 400샘플을 확인하고 기본 예제의 위치 검증 방식으로 고유 XY 400개, X/Y 각각 20개를 확인해줘. 검사 이미지 해상도는 400×1로 바꾸고 같은 새 Container 안에 검사 노드를 둔 뒤 정리해줘.
현재 애니메이션 상태를 복구용 TOX로 저장하고 Amp=0, Offset=0/0.5/1에서 출력을 확인해줘. v=1에서는 흰색 원 400개가 보이고 원끼리 겹치거나 화면에서 잘리지 않아야 해.
0.5의 지름이 1의 절반이고 색의 Blue가 Red/Green보다 큰지 확인해줘.
복구 후 약 1초 간격 3장에서 색·크기 변화를 확인해줘.
Z=2.4의 고정 출력과 TOX 재로드 출력을 비교하고 시간식을 복구해줘. 검사 복제본은 정리하고 최종 TOX를 저장해줘.
원본 TOE는 덮어쓰지 마. 실제 위치/원 수, 오류·경고, 저장 경로, 미검증 항목을 보고해줘.
